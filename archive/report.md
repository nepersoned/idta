# GNN 기반 사기 리뷰 탐지 프로젝트 보고서

---

## 1. 프로젝트 개요

### 1-1. 무엇을 하는 프로젝트인가

온라인 쇼핑이나 음식점 예약을 할 때 우리는 리뷰를 참고한다. 그런데 이 리뷰들 중 일부는 경쟁 업체를 망하게 하거나 특정 가게를 띄우기 위해 돈을 받고 조직적으로 작성된 가짜 리뷰, 즉 **사기 리뷰(스팸 리뷰)** 다.

이 프로젝트는 Yelp(미국 맛집/업소 리뷰 플랫폼) 데이터를 사용하여 **어떤 리뷰가 사기인지 자동으로 탐지하는 AI 모델**을 만드는 것을 목표로 한다.

### 1-2. 왜 GNN(그래프 신경망)을 사용하는가

일반적인 AI 모델은 리뷰 하나만 보고 판단한다. 하지만 교묘하게 작성된 사기 리뷰는 텍스트만 보면 진짜처럼 보인다. 이럴 때 **"이 리뷰를 쓴 사람의 다른 리뷰들은 어떤가?", "같은 가게에 비슷한 시기에 같은 별점을 남긴 다른 리뷰들은 어떤가?"** 라는 맥락이 중요해진다.

GNN은 리뷰들 사이의 **관계(연결)**를 그래프로 표현하고, 이웃 리뷰들로부터 정보를 모아 판단한다. 혼자 판단하는 것보다 주변 맥락을 함께 보기 때문에 탐지 성능이 높다.

| 방식 | 판단 기준 | 한계 |
|---|---|---|
| 일반 분류 모델 | 리뷰 텍스트, 별점 등 개별 정보 | 교묘한 사기 리뷰는 개별적으로 보면 정상처럼 보임 |
| GNN | 개별 정보 + 이웃 리뷰와의 관계 정보 | 관계 설계가 핵심 |

## 2. 데이터 소개 및 탐색적 분석 (EDA)

> EDA(Exploratory Data Analysis, 탐색적 데이터 분석)란 모델을 만들기 전에 데이터를 다양한 방식으로 살펴보고 특성을 파악하는 과정이다. "데이터가 어떻게 생겼는지" 먼저 이해해야 모델을 제대로 설계할 수 있다.

### 2-1. 데이터셋 기본 정보

사용 데이터는 **YelpZip** 데이터셋으로, Yelp 플랫폼의 리뷰 데이터를 기반으로 연구용으로 공개된 스팸 탐지 벤치마크 데이터셋이다.

| 항목 | 내용 |
|---|---|
| 전체 리뷰 수 | 608,458건 |
| 정상 리뷰 | 528,019건 (86.8%) |
| 사기 리뷰 | 80,439건 (13.2%) |
| 수집 기간 | 2004년 10월 - 2015년 초 |
| 결측치 | 없음 |

**컬럼 설명**

| 컬럼명 | 설명 |
|---|---|
| user_id | 리뷰를 작성한 사용자 고유 번호 |
| prod_id | 리뷰 대상 가게/업체 고유 번호 |
| rating | 별점 (1.0 - 5.0점) |
| label | 진위 여부 (원본: 정상=1, 사기=-1) |
| date | 리뷰 작성 날짜 |
| text | 리뷰 본문 |
| tag | 라벨의 문자열 버전 (normal/fake) |

**필수 전처리: 라벨 변환**

원본 데이터의 라벨 기준이 일반적인 머신러닝 관례와 반대로 설정되어 있어 변환이 필요하다.

| 구분 | 원본 값 | 변환 후 |
|---|---|---|
| 정상 리뷰 | 1 | 0 |
| 사기 리뷰 | -1 | 1 |

이 변환 없이 학습하면 모델이 정상 리뷰를 사기로, 사기 리뷰를 정상으로 분류하게 된다.

---

### 2-2. 클래스 불균형 (라벨 분포)

![Label & Rating Distribution](dist_basic.png)

전체 리뷰 중 사기 리뷰는 **13.2%(약 8만 건)** 에 불과하다. 나머지 86.8%는 정상 리뷰다.

**왜 이게 문제인가?**

만약 모델이 모든 리뷰를 무조건 "정상"이라고 예측해도 정확도가 86.8%가 된다. 숫자만 보면 높은 성능처럼 보이지만 사기 리뷰를 하나도 못 잡은 쓸모없는 모델이다. 이런 상황을 **클래스 불균형(class imbalance)** 이라고 한다.

**어떻게 대응하는가?**

1. **평가 지표 교체**: 정확도(Accuracy) 대신 PR-AUC와 Macro F1을 사용한다. 이 지표들은 소수 클래스(사기 리뷰)를 얼마나 잘 잡아내는지를 제대로 측정한다.
2. **학습 가중치 조정**: 학습 시 사기 리뷰 샘플에 더 큰 패널티를 부여해서 모델이 사기 리뷰를 더 집중해서 학습하게 만든다.

---

### 2-3. 별점 분포와 사기 리뷰의 특징

**전체 별점 분포**

전체 리뷰는 4-5점에 몰려있는 우편향 분포를 보인다. 대부분의 사람들은 좋은 경험을 했을 때 리뷰를 더 많이 남기는 경향이 있다.

**정상 리뷰 vs 사기 리뷰의 별점 차이**

| 별점 | 정상 리뷰 | 사기 리뷰 | 해석 |
|---|---|---|---|
| 1점 | 적음 | **상대적으로 많음** | 경쟁 업체 공격 ("1점 테러") |
| 2-3점 | 적음 | 적음 | 차이 없음 |
| 4점 | 많음 | 보통 | 정상이 더 많음 |
| 5점 | 가장 많음 | **상대적으로 많음** | 특정 업체 띄우기 ("5점 도배") |

사기 리뷰는 1점과 5점, 즉 **극단 별점에 집중**되는 특징을 보인다. 이는 사기 리뷰 작업장의 두 가지 영업 방식(경쟁 업체 공격 / 특정 업체 띄우기)과 정확히 일치한다.

**GNN 설계 시사점**: 같은 가게에 같은 별점을 남긴 리뷰들끼리 연결하면 작업장 패턴을 포착할 수 있다.

---

### 2-4. 사용자 / 상품 활동량 분포

![User & Product Distribution](dist_user_prod.png)

**사용자별 리뷰 수 분포**

대부분의 사용자는 리뷰를 거의 쓰지 않고, 소수의 헤비 유저가 대부분의 리뷰를 작성한다. 이런 분포를 **파워 로우(Power-law)** 라고 한다. 유튜브 구독자 수나 SNS 팔로워 수처럼 현실 세계의 많은 네트워크 데이터에서 나타나는 전형적인 형태다.

**상품별 리뷰 수 분포**

마찬가지로 파워 로우를 따른다. 일부 인기 상품은 최대 7,500건 이상의 리뷰를 보유하며, 이런 인기 상품이 작업장의 주요 타겟이 된다.

**사용자별 사기 리뷰 비율 분포 (핵심 발견)**

이 그래프에서 가장 중요한 발견이 나온다. 분포가 **0 근처(전부 정상)와 1 근처(전부 사기)에서만 높게 나타나는 이중 피크(bimodal) 형태**를 보인다.

| 구간 | 의미 |
|---|---|
| 0.0 - 0.1 | 거의 100% 정상 리뷰만 쓰는 일반 사용자 |
| 0.1 - 0.8 | 정상과 사기를 섞어 쓰는 사용자 (거의 없음) |
| 0.8 - 1.0 | 거의 100% 사기 리뷰만 쓰는 전용 계정 |

중간 비율의 사용자가 거의 없다는 것은 "일반인이 가끔 나쁜 리뷰를 남기는" 것이 아니라, **전용 계정을 운영하는 조직적인 작업장이 체계적으로 사기 리뷰를 생산**한다는 강력한 증거다.

**GNN 설계 시사점**: 같은 사용자가 작성한 리뷰끼리 연결하면, 작업장 계정의 사기 신호가 해당 사용자의 모든 리뷰로 전파되어 탐지가 쉬워진다.

### 2-5. 시간 기반 분포

![Time Distribution](dist_time.png)

**월별 리뷰 수 추이**

정상-사기 리뷰 모두 2004년부터 꾸준히 증가한다. 2015년 초에 급감하는 것은 데이터 수집이 완료되지 않았기 때문으로, 실제 리뷰가 줄어든 것이 아니다.

**월별 사기 비율 추이**

| 시기 | 특성 | 이유 |
|---|---|---|
| 2004 - 2006년 | 변동성 크고 최대 24%까지 급등 | 데이터가 적어 통계적으로 불안정 |
| 2007 - 2011년 | 전체 평균(13.22%) 수준으로 안정 | 충분한 데이터로 안정화 |
| **2012년 전반기** | **15-16%로 평균 대비 지속 높음** | **특정 작업장 집중 운영 시기** |
| 2013 - 2015년 | 다시 평균 수준으로 수렴 | 작업장 활동 감소 추정 |

2012년 1-6월은 약 6개월간 사기 비율이 15-16%로 전체 평균보다 2-3%p 높게 지속된 특이 구간이다. 이는 통계적 노이즈가 아니라 실제 작업장 활동 집중을 반영한다.

**샘플링 전략 시사점**: 이 구간의 데이터를 사용하면 더 높은 사기 비율의 데이터를 확보하여 모델 학습에 유리하다.

### 2-6. t-SNE 시각화

![t-SNE](tsne.png)

**t-SNE가 무엇인가?**

t-SNE는 여러 개의 피처(특징)를 가진 데이터를 2차원 평면에 압축해서 보여주는 시각화 도구다. "비슷한 특성을 가진 데이터는 가깝게, 다른 특성을 가진 데이터는 멀게" 배치한다. 정상 리뷰와 사기 리뷰가 2차원 평면에서 잘 분리되면 수치 피처만으로도 구별이 쉽다는 의미다.

**사용한 피처 6개**: 별점, 사용자 리뷰 수, 상품 리뷰 수, 사용자별 사기 리뷰 비율, 텍스트 길이, 작성 월

**결과 해석**

- 정상(파란색)과 사기(주황색)가 완전히 분리되지 않고 중간에 섞여있다.
- 단, 양 끝에는 한 종류만 모여있는 순수 클러스터가 존재한다.

이는 **수치 피처 6개만으로는 모든 사기 리뷰를 완벽히 구별할 수 없다**는 뜻이다. 개별 리뷰의 정보만 보면 정상처럼 보이는 사기 리뷰들이 존재한다. 이래서 GNN이 필요하다. 개별 정보만으로 판단이 어려운 리뷰도, 주변 이웃(같은 사용자의 다른 리뷰, 같은 가게에 같은 별점을 남긴 리뷰)을 함께 보면 탐지가 가능해진다.

### 2-7. EDA 요약: 무엇을 발견했는가

| 발견 | 의미 | 모델 설계에 반영하는 방법 |
|---|---|---|
| 정상 86.8% vs 사기 13.2% (클래스 불균형) | 단순 정확도는 의미 없음 | PR-AUC/Macro F1로 평가, 학습 가중치 조정 |
| 사기 리뷰의 극단 별점 집중 (1점, 5점) | 작업장이 1점 테러 / 5점 도배 수행 | R-S-R 엣지 설계 (같은 가게 + 같은 별점 연결) |
| 사용자별 사기 비율의 이중 피크 | 사기 전용 계정 존재, 조직적 작업장 운영 | R-U-R 엣지 설계 (같은 사용자 리뷰 연결) |
| 상품별 리뷰 파워 로우 집중 | 인기 상품이 주요 타겟 | 상위 상품 기준 샘플링 가능 (Strategy A) |
| 2012년 전반기 사기 비율 급등 | 특정 시기 작업장 집중 운영 | 해당 기간 기준 샘플링 가능 (Strategy C) |
| t-SNE에서 수치 피처만으론 불완전한 분리 | 개별 정보만으론 한계 있음 | 그래프 구조 활용 필수, 텍스트 임베딩 추가 시 향상 기대 |

## 3. 데이터 전처리 및 그래프 구성

### 3-1. 샘플링 전략

전체 60만 건을 한 번에 처리하기에는 계산 비용이 크다. 세 가지 전략으로 샘플링하여 각각 실험하고 비교한다.

| 전략 | 방법 | 노드 수 | 스팸 비율 | 선정 근거 |
|---|---|---|---|---|
| Strategy A | 리뷰 수 상위 13개 상품 필터링 | 48,608건 | 11.33% | 인기 상품이 작업장 주요 타겟 (EDA 확인) |
| Strategy C | 스팸 비율 피크 구간 (2012.01-06) 필터링 | 48,586건 | 14.59% | 해당 기간 사기 비율 15-16%로 전체 평균 대비 가장 높음 (EDA 확인) |
| **Strategy ACO** | **고스팸 월 필터 + 그리디 그래프 탐색** | **≤50,000건** | **~20%** | **시간·상품 두 축을 동시에 최적화 (하단 상세 설명)** |

모든 전략은 적정 실험 규모(10,000-50,000개)에 해당하며, 학습 / 테스트 분할은 80:20 비율로 stratified 샘플링(사기 비율 유지)을 적용한다.

**Strategy ACO 상세**

단순 무작위 추출 금지 원칙을 준수하면서 스팸 밀도를 극대화하기 위해 두 단계 결정론적 탐색을 설계하였다.

**1단계 — 고스팸 월 필터링 (시간 축)**

전체 월별 스팸 비율을 계산하여 전체 평균(13.22%)을 초과하는 43개 월만 추출하여 탐색 풀을 구성한다. 필터링 결과 351,436건(스팸 14.45%), 상품 4,772개, 유저 169,642명의 풀이 형성된다.

**2단계 — 그리디 그래프 탐색 (상품 축)**

1단계 풀 위에서 상품-유저 이분 그래프를 구성하고, 개미군집 최적화(ACO) 구조를 차용한 결정론적 탐색을 수행한다. 각 "개미"는 고스팸 점수(`spam_ratio × log(1 + degree)`) 상위 15개 상품에서 하나씩 출발하여, 매 단계 τ(페로몬) × η(휴리스틱) 값이 가장 높은 인접 노드를 argmax로 선택한다. 랜덤 요소가 전혀 없어 재현성이 완전히 보장된다.

- **페로몬 업데이트**: 방문 집합의 리뷰 수 가중 스팸 비율을 quality로 적립 (증발율 ρ=0.15)
- **수렴**: Iter 4부터 Weighted Spam Quality 0.1980 이상에서 안정적으로 수렴, 최고 0.1987
- **최종 선택**: 페로몬 기준 상위 상품들로 최대 50,000건 구성

**탐색 전략 비교 — 결정론적 선택(argmax) vs 확률적 선택(softmax)**

이론적으로 ACO에서는 확률적 선택이 다양성을 확보하여 더 좋은 해를 찾는 것으로 알려져 있다. 그러나 실험 결과 이 데이터에서는 결정론적 선택이 월등히 우수했다.

| 선택 방식 | Best Spam Quality | 최종 스팸 비율 |
|---|---|---|
| 결정론적 argmax (채택) | **0.1987** | **18.94%** |
| softmax 확률적 선택 | 0.1368 | 14.73% |

YelpZip에서 스팸 클러스터는 소수의 인기 상품에 극도로 집중되어 있다. 이런 구조에서는 탐색 다양성(exploration)보다 고품질 클러스터 집중 활용(exploitation)이 효과적이다. 확률적 선택은 낮은 품질 노드로의 이탈을 허용하여 페로몬이 분산되고 스팸 quality가 오히려 하락하는 결과를 낳았다.

### 3-2. 그래프 구성 방법

GNN에서 데이터는 노드(node)와 엣지(edge)로 이루어진 그래프로 표현된다.

- **노드(node)**: 각각의 리뷰 하나하나
- **엣지(edge)**: 리뷰들 사이의 연결 관계

**노드 피처 (각 리뷰에 부여하는 숫자 정보, 5개)**

| 피처 | 내용 | 사용 이유 |
|---|---|---|
| rating | 별점 (1-5점) | 사기 리뷰는 극단 별점 집중 (EDA 확인) |
| user_cnt | 해당 사용자가 쓴 전체 리뷰 수 | 작업장 계정은 리뷰를 대량으로 작성 |
| prod_cnt | 해당 상품의 전체 리뷰 수 | 인기 상품일수록 작업장 타겟 가능성 높음 |
| text_len | 리뷰 텍스트 길이 | 사기 리뷰는 획일적이거나 짧은 경향 |
| month | 리뷰 작성 월 | 특정 시기 집중 활동 패턴 포착 |

모든 피처는 스케일 차이를 없애기 위해 StandardScaler로 정규화한다.

**엣지 설계 (리뷰들을 어떻게 연결할 것인가)**

*R-U-R (Review-User-Review): 같은 사용자가 쓴 리뷰끼리 연결*

동일 사용자의 리뷰들이 서로 연결된다. 작업장 계정이 쓴 리뷰들은 이 연결을 통해 서로 "사기 정보"를 주고받게 된다. EDA에서 확인한 사기 전용 계정 패턴을 직접 활용하는 가장 강력한 엣지다. 연결이 너무 많아지는 것을 막기 위해 같은 사용자 내에서 최대 30개 리뷰만 연결한다.

*R-S-R (Review-Star-Review): 같은 가게에 같은 별점을 남긴 리뷰끼리 연결*

동일 상품에 동일 별점을 남긴 리뷰들이 서로 연결된다. 작업장이 특정 가게에 집중적으로 같은 별점을 남기는 패턴을 포착한다. R-U-R을 보완하는 엣지다.

## 4. 모델 설계 및 학습

### 4-1. 사용 모델: GCN (Graph Convolutional Network)

GCN은 GNN 계열 중 가장 기본적인 구조다. 작동 방식은 다음과 같다.

1. 각 노드(리뷰)가 자신의 피처를 가지고 있다.
2. GCN은 이웃 노드들의 피처를 평균 내어 자신의 표현에 합친다.
3. 이 과정을 레이어(층)마다 반복한다. 레이어가 깊을수록 더 먼 이웃의 정보도 반영된다.
4. 최종적으로 각 노드가 "정상인가 사기인가"를 분류한다.

이 프로젝트에서는 고급 모델보다 **기본 GCN으로 베이스라인 성능을 먼저 측정**하고, 추후 고도화 여부를 판단하는 전략을 취한다.

### 4-2. 모델 구조

```
입력: 리뷰당 5개 수치 피처
  → GCNConv(5 → 64차원) + ReLU 활성화 + Dropout(50%)
  → GCNConv(64 → 64차원) + ReLU 활성화 + Dropout(50%)
  → Linear(64 → 2)  : 정상(0) 또는 사기(1) 분류
```

- **ReLU**: 음수 값을 0으로 처리하는 활성화 함수. 모델이 비선형적인 패턴을 학습할 수 있게 한다.
- **Dropout(50%)**: 학습 중 무작위로 50%의 연결을 끊어 모델이 특정 패턴에만 과도하게 의존하는 것을 방지한다(과적합 방지).

### 4-3. 학습 설정

| 항목 | 값 | 이유 |
|---|---|---|
| Optimizer | Adam (lr=0.01) | 자동으로 학습률을 조정하는 안정적인 최적화 알고리즘 |
| Weight Decay | 5e-4 | 모델 가중치가 너무 커지는 것을 방지 |
| Epochs | 100 | 전체 학습 데이터를 100번 반복 학습 |
| Loss | CrossEntropy | 분류 문제의 표준 손실 함수 |
| 클래스 불균형 대응 | class_weight = [1.0, n_정상 / n_사기] | 사기 리뷰 샘플에 더 큰 패널티를 부여하여 소수 클래스 학습 강화 |

### 4-4. 평가 지표

**PR-AUC (Precision-Recall Area Under Curve)**

정밀도(Precision, "사기라고 예측한 것 중 실제 사기 비율")와 재현율(Recall, "실제 사기 중 잡아낸 비율") 사이의 트레이드오프를 곡선으로 그렸을 때 그 면적. 클래스 불균형이 심한 상황에서 소수 클래스 탐지 능력을 가장 정확하게 측정하는 지표다.

**Macro F1**

정상 클래스와 사기 클래스 각각의 F1 점수를 구한 뒤 단순 평균 낸 값. F1은 정밀도와 재현율의 조화평균으로, 어느 한쪽에 치우치지 않고 균형 있는 성능을 측정한다. Macro는 두 클래스를 동등하게 취급하므로 소수 클래스(사기)가 무시되지 않는다.

## 6. 결과 분석

### 6-1. 전략 간 비교

| 전략 | PR-AUC | Macro F1 | 스팸 비율 | 엣지 수 |
|---|---|---|---|---|
| Strategy A | 0.3158 | 0.5712 | 11.33% | 50,521 |

| ACO + R-C-R | 0.4082 | 0.5953 | 18.94% | — |
| ACO + R-B-R + R-C-R | 0.4041 | 0.5831 | 18.94% | — |

### 6-2. R-B-R 커스텀 엣지의 효과

**R-B-R (Review-Beam-Review)** 는 GNN이 학습한 사기 확률을 역이용해 새로운 엣지를 생성하는 자기지도 방식이다.

- **빔서치 경로**: 사기 확률 상위 500개 노드를 출발점으로, 매 단계 이웃 중 사기 확률이 높은 상위 5개 경로만 유지(Beam Width=5, Max Depth=6). 경로의 평균 사기 확률이 임계값(상위 1% × 0.9) 이상인 경우에만 경로 채택
- **생성된 엣지**: 같은 빔 경로에 등장한 리뷰 쌍 → R-B-R 엣지. 총 1,923개, R-B-R 노드 사기 비율 62.6% (전체 18.94% 대비 3.3배)
- **과적합 방지 3중 처방**: DropEdge(R-B-R 엣지 30% 무작위 제거) + 엣지 가중치(R-B-R=0.2, 나머지=1.0) + Early Stopping(val PR-AUC, patience=15)

**결과**: R-B-R 단독 PR-AUC +0.2%(0.4107 → 0.4116). 엣지 비중(3.1%) 대비 영향은 제한적이었다. R-C-R 병합 시 오히려 성능 하락(-1.6%)이 발생해, 두 방식의 중복 연결로 인한 노이즈 간섭이 확인되었다. 커스텀 엣지 방식은 방법론적 기여(GNN 자체 예측 활용, 자기지도 학습 구조)에 의의가 있으며, 수치 성능 개선은 미미한 수준이었다.

### 6-3. Strategy ACO가 가장 좋은 이유

**이유 1: 시간·상품 두 축을 동시에 최적화한다**

Strategy C는 특정 기간(2012.01-06)을 고정하여 그 안의 모든 데이터를 사용한다. 반면 Strategy ACO는 전체 데이터에서 스팸 비율이 높은 월들을 먼저 추려 탐색 풀을 구성한 뒤, 그 안에서 다시 스팸 밀도가 높은 상품 클러스터를 그리디 탐색으로 선별한다. 시간과 상품 두 차원을 모두 고려하기 때문에 단일 축 필터링보다 스팸 밀도가 높다.

**이유 2: 그래프 연결성이 보존된 상태에서 스팸을 집중시킨다**

단순 무작위 추출은 연결성을 파괴하지만, ACO 탐색은 상품-유저 이분 그래프의 실제 엣지를 타고 이동하므로 최종 서브그래프 내 노드들이 실제로 연결되어 있다. 스팸 밀도를 높이면서도 GNN이 요구하는 그래프 연결성을 함께 만족한다.

**이유 3: 스팸 비율 ~20%로 학습 데이터 품질이 가장 높다**

스팸 비율이 높을수록 모델이 사기 패턴을 더 많이 학습할 수 있다. Strategy ACO의 ~20%는 전체 평균(13.22%)의 1.5배, Strategy C(14.59%)의 1.4배다. 이것이 PR-AUC 기준 C 대비 +14.9% 향상으로 이어진 핵심 원인이다.

### 6-4. Strategy C가 A보다 좋은 이유 (참고)

Strategy C의 엣지 수는 350,167개로 A(50,521개)의 약 7배다. 2012년 전반기 작업장 집중 운영 시기에 같은 별점·같은 가게 리뷰가 대량 발생했기 때문이다. GCN은 그래프가 밀집될수록 사기 신호 전파가 더 잘 이루어진다.

### 6-5. 베이스라인 모델로서의 의의

이 실험은 텍스트 임베딩 없이 수치 피처 5개와 기본 엣지 2종류만으로 구성한 **최소한의 베이스라인**이다. 그럼에도 PR-AUC 0.32-0.41, Macro F1 0.57-0.60을 달성했다. 이는 그래프 구조와 샘플링 전략 자체가 사기 탐지 성능에 결정적인 영향을 미침을 입증하는 결과다.

## 7. 발견된 사기 패턴 요약

EDA와 모델 실험을 통해 파악된 주요 사기 리뷰 패턴이다.

**패턴 1: 전용 계정 운영**

사기 리뷰를 작성하는 계정은 거의 100% 사기 리뷰만 작성한다. 일반인이 가끔 나쁜 리뷰를 남기는 것이 아니라 전용 계정을 따로 만들어 운영한다.

**패턴 2: 극단 별점 집중**

사기 리뷰는 1점(경쟁 업체 공격) 또는 5점(특정 업체 홍보)에 집중된다. 2-4점의 중간 별점은 거의 남기지 않는다.

**패턴 3: 특정 가게 집중 타겟팅**

인기 있는 상위 상품에 리뷰가 집중된다. 사기 리뷰도 마찬가지로 이런 인기 상품에 집중된다.

**패턴 4: 시간 집중 운영**

2012년 전반기처럼 특정 기간에 사기 비율이 급등하는 패턴이 있다. 작업장이 특정 시기에 집중적으로 운영된다.

|---|---|
| 텍스트 미활용 | 리뷰 본문을 전혀 읽지 않고 길이만 사용. 사기 리뷰 특유의 문체나 내용 패턴을 포착하지 못함 |
| 기본 엣지만 사용 | R-U-R, R-S-R 2가지 외에 추가적인 관계 유형 미반영 |
| GCN의 구조적 한계 | 이웃 노드를 단순 평균으로 집계. "이 이웃이 더 중요하다"는 식의 가중 처리 불가 |

### 8-2. 성능 향상을 위한 다음 단계

1. **텍스트 임베딩 추가**: BERT나 TF-IDF를 사용해 리뷰 본문의 의미를 노드 피처에 반영. t-SNE에서 수치 피처만으로는 분리가 불완전했던 한계를 극복 가능
2. **엣지 다양화**: 텍스트 유사도 기반 R-V-R 엣지(내용이 비슷한 리뷰끼리 연결), 시간 근접 기반 엣지 추가
3. **모델 고도화**: GAT(Graph Attention Network, 중요한 이웃에 더 높은 가중치 부여)나 GraphSAGE(대규모 그래프에 효율적)로 교체
4. **전략 최적화**: Strategy A와 C 비교 결과를 바탕으로 더 최적화된 샘플링 전략 탐색
